# ViceBase - GTA VI Resource Hub

Independent GTA VI guides, official video links, launch countdown, troubleshooting, and a U.S. retailer comparison.

This repository contains a static Vercel-ready website in `site/`, editorial source in `source/` and a separately provisioned Neon schema in `database/`. Vercel project root directory: `site`.

The storefront prices are manually checked snapshots, not live automated feeds. Unofficial fan project; not affiliated with Rockstar Games.
