GTA 6 latest update: patch notes and bug fix checker

Rockstar's November 23 launch update fixes seven categories of GTA 6 bugs. Check your symptom, console and next step without deleting game saves.

LATEST DOCUMENTED ROCKSTAR LAUNCH PATCH · NOV 23, 2026

What did the GTA 6 update fix?

Rockstar lists seven categories of fixes: game crashes, weather stuck in one state, autosave failures, missed story phone calls, Wanted Level that would not clear, an unusable gym deadlift bar, and a partner failing to hand over stolen goods for sale.

Addressed in Nov 23 patch

Crashing or freezing

Rockstar fixed several causes of crashes. It does not say every crash is eliminated.

  1. Check for the current game update and your console's system update.
  2. Note whether the game returns to the dashboard or the entire console turns off; stop if there is a hardware safety warning.
  3. Restart normally, retry once and record the exact error if the crash remains.

How to check for a GTA 6 update

PS5 / PS5 Pro

  1. Highlight GTA VI on the console home screen.
  2. Press Options and choose Check for Update.
  3. Install the update and restart the game normally.

Xbox Series X|S

  1. Open My games & apps.
  2. Go to Manage → Updates.
  3. Install the available game update and reopen GTA VI.
