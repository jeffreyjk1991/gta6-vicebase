// THE SOURCE OF TRUTH

What's confirmed?

Rockstar has named six parts of the state of Leonida, but it has not provided a fully verified public street-by-street map. We distinguish named regions from editorial sightseeing themes. The drawn road network and markers are intentionally conceptual, not navigational or collectible coordinates.

  • Vice City — Coastal metropolis
  • Leonida Keys — Island chain
  • Grassrivers — Wetlands
  • Port Gellhorn — Gulf coast
  • Ambrosia — Heartland
  • Mount Kalaga — Northern wilderness
