How to Save in GTA 6: Manual Save and Autosave

Learn where GTA VI saves are, how to use the 15 manual slots and what to do when the Save Game option is unavailable.

HANDS-ON REPORTSUPDATED NOV 19, 20266 MIN READ
QUICK ANSWER

Pause with Options (PS5) or Menu (Xbox), choose Game, then Save Game and select a manual save slot. Hands-on reviewers report 15 manual slots and a separate autosave. Save Game is normally unavailable during missions, so return to free roam to save manually.

EDITORIAL SOURCE NOTE. This is a dated summary of launch-day reports, not a claim of GTASIX first-hand testing. Options and scores may change.

What to know

01

Press Options on PS5 or Menu on Xbox to open the pause menu.

02

Choose Game → Save Game, pick an available slot, and confirm.

03

Use separate slots for important chapters; do not overwrite your only backup.

04

Game → Load Game restores a selected save; check the save timestamp first.

05

If Save Game is greyed out, finish the current mission and retry in free roam.

06

Autosave is convenient but changes over time. Save manually after longer sessions, particularly before using cheats.

Frequently asked questions

How do you save GTA 6?

Pause the game and select Game → Save Game while in free roam.

How many GTA 6 save slots are there?

Hands-on guides report 15 manual slots and an autosave.

Why is Save Game greyed out?

Manual saving is unavailable during many missions and early sequences.

Does GTA 6 autosave?

Yes; use a manual save if you want to preserve a specific point.
